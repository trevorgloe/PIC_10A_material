There is a build error on line 20, where the constructor `Holder h2(&v2)` is invoked. There are 2 constructors for `Holder`, one that takes in a regular `vector<int>` reference, and the other that takes in a `vector<int>` pointer. On line 20, the code attempts to call a constructor with the address of a `const vector<int>`. A regular point (one which is not a pointer to const) cannot bind to const data. So the pointer constructor will not work. The reference constructor cannot take in a raw memory address and create a reference, so the reference constructor does not work either. Thus, there are no valid constructors to accomodate this argument.
